# Contributing to AxonerAI

🎈 Thanks for your interest in contributing to AxonerAI!

The goal of this project is to provide a type-safe, high-performance agentic AI framework in Rust with a **minimal runtime footprint and maximum flexibility**. We want to make it easy for developers to build powerful AI agents without the overhead of interpreted languages.

## Code of Conduct

This project adheres to the [Rust Code of Conduct][coc]. By participating, you are expected to uphold this code.

[coc]: CODE_OF_CONDUCT.md

## How to Contribute

### Reporting Issues

If you find a bug or have a feature request, please open an issue on GitHub. When reporting a bug, please include:

- A clear title and description.
- Steps to reproduce the issue.
- Expected vs. actual behavior.
- Any relevant logs or error messages.

### Pull Requests

We welcome pull requests! Here's the recommended workflow:

1.  **Fork the repository** and create a new branch for your feature or fix.
2.  **Make your changes**. Try to keep your changes focused and atomic.
3.  **Add tests** if applicable. We want to ensure stability as we grow.
4.  **Run tests** locally to ensure everything works (`cargo test`).
5.  **Submit a Pull Request**. Provide a clear description of what you changed and why.

### Coding Style

- We follow standard Rust formatting conventions (`rustfmt`).
- Please run `cargo fmt` before submitting your code.
- Ensure `cargo clippy` does not report any new warnings.
